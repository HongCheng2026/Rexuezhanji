# 游戏数值总纲

本文档用于指导飞机小游戏内的核心伤害、敌机血量、敌机减伤和关卡成长规则。目标是让 Codex 可以根据本文档直接设计和实现游戏数值。

## 1. 玩家伤害公式

最终伤害计算公式：

```text
最终伤害 = (飞行员伤害 + 战机伤害) * 战机升级系数 * 游戏内道具伤害系数 * 敌机承伤系数
```

### 重要说明

- “敌机减伤”不要直接作为乘法系数使用。
- 程序中建议拆成两个概念：
  - 敌机减伤率：敌机减少多少伤害，例如 10% 减伤率。
  - 敌机承伤系数：真正参与最终伤害计算的系数。
- 换算公式：

```text
敌机承伤系数 = 1 - 敌机减伤率
```

例如：

```text
敌机减伤率 = 10%
敌机承伤系数 = 1 - 10% = 90% = 0.9
```

## 2. 玩家基础数值

| 数值项 | 初始值 | 程序建议字段 |
|---|---:|---|
| 飞行员伤害 | 50 | pilotDamage |
| 战机伤害 | 100 | fighterDamage |
| 战机升级系数 | 100% | fighterUpgradeMultiplier |
| 游戏内道具伤害系数 | 读取拾取道具文档 | pickupWeaponDamageMultiplier |

### 战机升级系数

- 初始为 100%，即 `1.0`。
- 最高为 200%，即 `2.0`。
- 该系数只影响玩家最终伤害，不影响敌机血量。

## 3. 游戏内道具伤害系数

游戏内拾取道具的伤害系数以文档《飞机拾取道具升级数值规范.md》为准。

当前三种武器道具的伤害系数范围如下：

| 道具名称 | 类型 | 伤害系数范围 |
|---|---|---:|
| 穿云针 | 点伤害 | 100% - 200% |
| 裂风波 | 范围伤害 | 100% - 150% |
| 灵蜂弹 | 自动追踪伤害 | 100% - 150% |

程序实现时，应根据当前武器等级读取对应的道具伤害系数。

## 4. 敌机基础血量

| 敌机类型 | 基础血量 | 程序建议字段 |
|---|---:|---|
| 敌军小飞机 | 100 | smallEnemyBaseHp |
| 精英战机 | 1000 | eliteEnemyBaseHp |
| BOSS 战机 | 10000 | bossEnemyBaseHp |

敌机最终血量计算公式：

```text
敌机最终血量 = 敌机基础血量 * 敌机血量系数
```

## 5. 章节成长规则

游戏从“序章”到“第七章节”。

- 序章：敌机血量和敌机减伤率没有章节加成。
- 第一章节：敌机血量系数增加 10%，敌机减伤率增加 10%。
- 第二章节：敌机血量系数增加 20%，敌机减伤率增加 20%。
- 第三章节：敌机血量系数增加 30%，敌机减伤率增加 30%。
- 以此类推，直到第七章节。

章节成长公式：

```text
章节加成 = 章节序号 * 10%
```

章节序号定义：

| 章节 | 章节序号 |
|---|---:|
| 序章 | 0 |
| 第一章节 | 1 |
| 第二章节 | 2 |
| 第三章节 | 3 |
| 第四章节 | 4 |
| 第五章节 | 5 |
| 第六章节 | 6 |
| 第七章节 | 7 |

## 6. 小关卡额外成长规则

每个章节有 10 个小关卡。

在每个章节内：

- 第 5 小关：敌机血量额外增加固定 10%，敌机减伤率额外增加固定 10%。
- 第 10 小关：敌机血量额外增加固定 10%，敌机减伤率额外增加固定 10%。
- 其他小关：没有额外小关加成。
- 第 10 小关只增加一次固定 10%，不要因为同时也是 5 的倍数而重复增加。

小关卡额外加成公式：

```text
如果小关卡编号为 5 或 10：
  小关卡额外加成 = 10%
否则：
  小关卡额外加成 = 0%
```

## 7. 敌机血量与减伤总公式

```text
总成长加成 = 章节加成 + 小关卡额外加成

敌机血量系数 = 1 + 总成长加成

敌机减伤率 = 总成长加成

敌机承伤系数 = 1 - 敌机减伤率

敌机最终血量 = 敌机基础血量 * 敌机血量系数
```

### 示例

第一章节第 1 小关：

```text
章节加成 = 10%
小关卡额外加成 = 0%
总成长加成 = 10%

敌机血量系数 = 110% = 1.1
敌机减伤率 = 10%
敌机承伤系数 = 90% = 0.9
```

第一章节第 5 小关：

```text
章节加成 = 10%
小关卡额外加成 = 10%
总成长加成 = 20%

敌机血量系数 = 120% = 1.2
敌机减伤率 = 20%
敌机承伤系数 = 80% = 0.8
```

第七章节第 10 小关：

```text
章节加成 = 70%
小关卡额外加成 = 10%
总成长加成 = 80%

敌机血量系数 = 180% = 1.8
敌机减伤率 = 80%
敌机承伤系数 = 20% = 0.2
```

## 10. 程序实现建议

### 推荐字段

```js
const playerStats = {
  pilotDamage: 50,
  fighterDamage: 100,
  fighterUpgradeMultiplier: 1.0
};

const enemyBaseHp = {
  small: 100,
  elite: 1000,
  boss: 10000
};
```

### 推荐计算函数

```js
function getStageBonus(stageInChapter) {
  return stageInChapter === 5 || stageInChapter === 10 ? 0.1 : 0;
}

function getChapterBonus(chapterIndex) {
  return chapterIndex * 0.1;
}

function getEnemyScaling(chapterIndex, stageInChapter) {
  const totalBonus = getChapterBonus(chapterIndex) + getStageBonus(stageInChapter);
  return {
    hpMultiplier: 1 + totalBonus,
    damageReductionRate: totalBonus,
    damageTakenMultiplier: 1 - totalBonus
  };
}

function getEnemyHp(baseHp, chapterIndex, stageInChapter) {
  const scaling = getEnemyScaling(chapterIndex, stageInChapter);
  return baseHp * scaling.hpMultiplier;
}

function getFinalDamage({
  pilotDamage,
  fighterDamage,
  fighterUpgradeMultiplier,
  pickupWeaponDamageMultiplier,
  enemyDamageTakenMultiplier
}) {
  return (
    (pilotDamage + fighterDamage) *
    fighterUpgradeMultiplier *
    pickupWeaponDamageMultiplier *
    enemyDamageTakenMultiplier
  );
}
```

### 实现口径

- 百分比在程序中统一使用小数表示，例如 100% 写作 `1.0`，150% 写作 `1.5`。
- 敌机减伤率最高在第七章节第 5/10 小关达到 80%，敌机承伤系数为 20%。
- 若后续增加第八章节或更高章节，需要注意敌机承伤系数不能低于 0。
- 若计算结果出现小数血量，建议向上取整，避免敌机血量被显示为小数。
- 若计算结果出现小数伤害，可以按游戏表现需要选择保留小数或四舍五入。
