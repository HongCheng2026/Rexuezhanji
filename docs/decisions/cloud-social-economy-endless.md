# 社交、经济与无尽模式上线决策

## 结论

- 正式域名的好友、排行榜、世界聊天、任务、成就、商店和无尽纪录，只通过 `GameGateway -> game-api` 访问云端。
- 浏览器不能直接读写社交表；排行榜成绩由服务端从云存档计算，客户端不再提交任意分数。
- 强化、领奖和购买都使用 `operationId` 与 `commit_profile_operation`，存档和流水在同一事务提交。
- 世界聊天首版只有世界频道。好友私聊和公会频道明确标记“未开放”。
- 普通关卡继续使用章节导演；无尽模式使用独立导演和独立数值，不能修改章节 BOSS 平衡。

## 模块边界

- H5 总视图只调度面板；好友/排行/聊天由 `socialFeaturePanelsView` 负责，无尽说明页由 `endlessModePanelView` 负责，云端领奖与购买状态由 `economyFeatureController` 负责。
- `game-api/index.ts` 保留鉴权、通用存档和路由；社交、经济、无尽、原子存档事务分别放在 `services/social.ts`、`services/economy.ts`、`services/endless.ts`、`services/profileTransaction.ts`。

## 无尽规则

- 使用第 1～9 章最终 BOSS，按顺序循环；第一只立即出现，之后每 30 秒一个节点，场上最多一只。
- 第 `n` 只生命为基础生命的 `n` 倍，攻击附加 `n × 10%`，减伤为 `n%`，90 只后继续线性增长。
- 最终减伤先扣战机基础破甲、技能破甲和临时破甲；最终伤害倍率最低为 0。
- 首版不发养成奖励，只保存最高击杀和最长生存。开始与结束使用云端票据校验。

## 发布门槛

发布顺序固定为：增量迁移、云函数、接口冒烟、同步发布目录、Netlify、正式域名验收、推送代码。数据库迁移失败时停止正式前端发布。
