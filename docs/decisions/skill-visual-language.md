# 战斗技能视觉语言

## 固定规则

- 普通三武器保留原有金、青、橙三套颜色，不承担局外养成识别。
- 所有“战机强化”获得的自动技能统一带 `#63ffb4` 翡翠识别层；各技能再用不同造型、辅色和运动方式区分。
- 自动技能只使用短尾迹、小范围光环和轻量命中特效，不制造全屏压暗，也不持续抖屏。
- 手动主动技能统一标记为 `premium`，允许使用短时战场聚焦、分层冲击环、光轴、残影和一次受控震屏。
- 自动连锁闪电以翡翠绿为主；手动连锁闪电以蓝白高压电弧为主。两者不得复用同一最终颜色表现。
- 自动引力井以暗绿为主、紫色为辅；手动黑洞以紫、蓝、白为主，必须有明显尺度和亮度差。

## 新增技能流程

1. 在 `Gameplay/Combat/skillVisualTheme.js` 登记视觉等级、主色、辅色、尾迹和造型语义。
2. 技能处理器只生成战斗数据，并给特效写入 `visualId` 与 `presentationTier`。
3. `canvasRenderer` 根据统一主题绘制，不在战机 ID、技能等级或 UI 中追加视觉判断。
4. 新增贴图只能通过 `Presentation/Assets/assets.js` 的运行时资源入口引用。
5. 被替代且确认没有任何运行时引用的旧素材，才移入项目根目录 `_废弃素材`；仍参与分层绘制的素材不得移动。

## 性能上限

- 自动技能每次触发最多新增一个主特效实体；连锁类按实际命中段数生成，但不得额外制造常驻粒子对象。
- 主动技能的高级表现优先使用 Canvas 即时路径，不新增常驻 DOM，不逐帧创建图片对象。
- 全屏聚焦层只在施法开始约 `0.34` 秒内出现，持续技能不能长期压暗战场。
