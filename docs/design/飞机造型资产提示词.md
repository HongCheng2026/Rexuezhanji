- 透明背景
- 2D 游戏资产
- 俯视角
- 精灵图
- 轮廓清晰
- 小尺寸可读

## 推荐组合

如果网页工具支持“正向提示词”和“负面提示词”，可以这样使用：

1. 正向提示词：复制上面任意一个飞机类型的英文提示词。
2. 负面提示词：复制“负面提示词”的英文版本。
3. 图片比例：建议使用 1:1 或 4:3。
4. 背景：选择透明背景。如果工具不支持透明背景，生成后再用抠图工具处理。
5. 风格：选择 2D、game asset、sprite、arcade、top-down。
