# 热血战姬 · 游戏主循环 & 模块导航树

> 全部基于 `src/h5/Shell/game-frame.html`（大厅真实按钮）、
> `featurePanelController.js`（面板路由）、`mainFeaturePanelsView.js`（分栏）、
> `lobbyController.js`（战斗/扫荡流程）的实际代码，不是拍脑袋。
>
> 关键对应：**主 UI 上每一个可点的入口 = 一个独立模块（房间/room）**，
> 与既有「一功能一房间」架构完全一致。下面的树 leaf 即独立模块。

核心一句话：
  战斗 = 「消耗 / 检验」端；养成 + 抽卡 = 「生产 / 积累」端；

### 支柱关系（你提的「2、3 都服务 1」）

```
        养成(2) ──┐
                    ├── 提升战力 ──► 战斗(1) 更强 ── 产出经济 ──┐
        抽卡(3) ──┘                                        │
                                                              ▼
                                                  反哺 养成(2)+抽卡(3)
```

- 抽卡拿到的 S/SS 战姬·战机 → 进养成强化 → 战力↑ → 战斗更轻松
- 战斗产出的金币/钻石/材料 → 反哺养成与抽卡（买强化、补抽卡货币）
- 这就是一个自洽的经济闭环，**战斗是唯一的价值出口，养成/抽卡是价值入口**

## 三、按你「三大支柱」归一下类

| 支柱 | 对应模块（上面树的 leaf） | 说明 |
|------|---------------------------|------|
| **1 飞机战斗（核心）** | 开始战斗 → 关卡选择 → 战斗 →（暂停 / 结算 / 关内商店）；活动 → 无尽战斗 → 无尽战报 | 关卡 与 无尽 彼此独立，共用战斗内核 |
| **2 养成（服务 1）** | 战机强化（属性 / 主动技能 / 被动模块）、战姬、战机（出战选择 / 购买） | 今后「战姬养成」= 在 pilotGallery 基础上扩展养成线 |
| **3 抽卡（服务 1）** | 星穹之翼抽卡 | 高端战姬 / 战机获取途径，产出喂养成 |

> 注意两个「非战斗但常被误认成战斗入口」的模块：
> - **图鉴**（enemyCodex）：只是敌机/敌弹查询，不参与战斗
> - **关内强化商店**（shopScreen）：是战斗结算里的一个子步骤，不是大厅商店

## 四、给架构的提示（顺手）

1. **每个 leaf 都是一个房间（room）**，和你既有的「一功能一房间」完全一致——这套导航树本身就是房间清单。
2. **三个「社交类」leaf（好友 / 排行榜 / 聊天）都指向 `socialFeaturePanelsView`**，建议以后拆成三个独立房间，否则这个 view 会变成 God View。
3. **「战机强化」是唯一用「独立整屏」而非「面板」的养成模块**——因为它交互重（属性/技能/模块装配）。其余养成（战姬/战机）走面板即可。
4. **无尽模式藏在「活动」下面**，从玩家心智上它更像战斗主线而非活动；若以后无尽要常驻，可考虑提到底部出击区与「开始战斗」并列。
