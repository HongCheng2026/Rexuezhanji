# 通用代码说明

`H5` 目录里放的是网页游戏核心文件：

- `index.html`
- `style.css`
- `game.js`
- `角色资产`

`shared` 目录里放平台无关的游戏核心：

- `balance.js`：伤害、敌机血量、道具系数和章节成长。
- `levels.js`：关卡、体力、BOSS 时间、升级项和拾取道具显示配置。
- `assets.js`：飞行员、战机、背景和战斗素材配置。
- `profile.js`：存档默认值、体力恢复、金币和存档规范化。
- `battleRules.js`：经验、评级、扫荡、升级价格和通关进度规则。

`小程序通用` 目录里放的是微信和抖音小程序能复用的轻量素材与存档逻辑。

当前 H5 版已经是可直接部署版本；小程序版因为平台 API 和页面语法不同，已经分到各自目录，后续改公共素材或基础数据时，从这里同步到对应平台目录。
