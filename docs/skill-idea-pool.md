# 热血战姬 · 技能创意池（纯机制罗列，无数值，供挑选）

> 用途：从下列 100 条「只描述机制、不含数值」的创意中挑选，再回填倍率/冷却/概率。
> 主动 = 玩家触发（按键/冷却）；被动 = 常驻生效。
> 编号 1–40 主动，41–100 被动。每条仅一个核心机制，便于组合与裁剪。

---

## 一、主动技能（1–40）

1. **全屏清弹** — 清除屏幕上所有敌方子弹。
2. **全屏轰炸** — 对全屏敌人造成一次伤害。
3. **时停** — 敌机与敌弹整体暂停。
4. **子弹时间** — 敌弹变慢，自己照常行动。
5. **护盾** — 获得一层可挡多次的护盾。
6. **无敌闪烁** — 短暂进入无敌状态。
7. **瞬移** — 传送到随机/指定安全点。
8. **分身** — 召唤分身复制本体火力。
9. **反弹盾** — 生成把来袭弹幕弹回的盾。
10. **追踪弹幕** — 发射自动锁敌的导弹。
11. **贯穿激光** — 发射一道可贯穿的激光。
12. **散弹爆发** — 一次性大范围散射齐射。
13. **轨道炮** — 从天而降的精准打击。
14. **身后地雷** — 在身后布下延迟爆炸物。
15. **引力井** — 把敌人吸向一点聚簇。
16. **冲击波** — 击退周围敌人。
17. **眩晕弹** — 使周围敌人陷入眩晕。
18. **冻结** — 冰冻敌人使其停止行动。
19. **燃烧领域** — 在身周留下持续灼烧区。
20. **毒云** — 释放一片持续伤害云。
21. **电磁脉冲** — 瘫痪敌人使其停火。
22. **召唤僚机** — 召唤跟随的辅助机。
23. **召唤炮台** — 在固定点生成自动炮台。
24. **自愈** — 恢复一定生命。
25. **吸血** — 一段时间内伤害转为回血。
26. **狂暴** — 短时间攻击力大幅提升。
27. **极速** — 短时间移动速度大幅提升。
28. **连射** — 短时间射速翻倍。
29. **蓄力炮** — 蓄力后发射超高伤一击。
30. **贯穿弹** — 发射可穿透多敌的弹。
31. **时间回溯** — 回到片刻前的位置/状态。
32. **替身木** — 用假身替你挡一次致命伤。
33. **炸弹** — 投掷范围爆炸物。
34. **闪现斩** — 瞬移到敌群中造成爆发伤害。
35. **流星雨** — 从屏幕上方砸下多发打击。
36. **连锁闪电** — 在敌人之间跳跃的电击。
37. **黑洞** — 生成吞噬弹幕与敌人的黑洞。
38. **标记狙击** — 标记强敌后被远程狙杀。
39. **怒气爆发** — 消耗资源放出全屏大招。
40. **镜像分身阵** — 召唤多体分身形成火力墙。

## 二、被动技能（41–100）

41. **侧翼火力** — 两侧自动开火。
42. **正面散射** — 正面宽扇自动开火。
43. **背后火力** — 向后自动开火。
44. **追踪弹** — 武器自动带追踪。
45. **贯穿** — 子弹可穿透敌人。
46. **爆裂** — 敌死时爆炸溅射。
47. **弹射** — 命中后弹向另一敌人。
48. **减速弹** — 命中使敌人变慢。
49. **灼烧弹** — 命中附加持续燃烧。
50. **冰冻弹** — 命中有几率冰冻。
51. **吸血弹** — 命中回血。
52. **护盾穿透** — 攻击无视部分护盾。
53. **破甲** — 攻击降低敌人防御。
54. **范围加成** — 爆炸伤害范围更大。
55. **射速提升** — 武器射速更快。
56. **伤害提升** — 所有伤害更高。
57. **多弹** — 每次射击额外多一发。
58. **子弹变大** — 子弹体积更大更好命中。
59. **子弹加速** — 子弹飞行更快。
60. **资源加成** — 击杀掉落更多。
61. **经验加成** — 获得经验更多。
62. **生命上限** — 生命上限提高。
63. **护甲** — 减少受到伤害。
64. **闪避** — 有几率完全躲过攻击。
65. **反伤** — 受击时反弹伤害。
66. **荆棘光环** — 身边有持续伤害光环。
67. **再生** — 随时间缓慢回血。
68. **拾取范围** — 拾取物吸取范围更大。
69. **磁吸** — 掉落物自动飞向你。
70. **开局护盾** — 每关开始自带护盾。
71. **复活** — 死亡后一次自动复活。
72. **减伤** — 承受伤害降低。
73. **反弹** — 碰到的弹幕被弹开。
74. **时停光环** — 身边敌人变慢。
75. **聚怪** — 轻微把敌人拉向身前。
76. **子弹抵消** — 有几率抵消飞来的弹。
77. **维修无人机** — 自动缓慢修血。
78. **自动炮塔** — 自动攻击最近敌人。
79. **僚机跟随** — 跟随的辅助机自动开火。
80. **蓄能** — 静止时积攒能量增伤。
81. **连击加成** — 连续命中提升伤害。
82. **暴击** — 攻击有几率造成重击。
83. **处决** — 低血敌人被一击斩杀。
84. **分裂** — 敌死时分裂出小弹。
85. **链伤** — 命中使附近敌人也受伤。
86. **标记** — 被命中的敌人受更多伤。
87. **减速光环** — 全场敌人略慢。
88. **沉默** — 敌人无法释放技能。
89. **致盲** — 敌人命中率下降。
90. **周期护盾** — 周期性获得小护盾。
91. **能量回充** — 主动技能冷却更快。
92. **灵活闪避** — 闪避动作更灵活。
93. **弹幕转化** — 抵消的弹变成自己子弹。
94. **镜像反射** — 侧面来的弹被反射。
95. **集火** — 所有火力偏向最前敌人。
96. **扇形聚焦** — 火力收拢成窄束增伤。
97. **暴走** — 生命越低攻击越高。
98. **救场** — 濒死时自动清一次屏。
99. **协同** — 装备多模块时整体增强。
100. **进化** — 随时间/关卡武器自动升级。
