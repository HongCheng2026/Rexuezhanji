# 01_剧情总纲

## 1. 故事定位

男性向轻剧情科幻空战。

核心卖点：

```text
玩家是唯一空战指挥官。
女性飞行员小队听从玩家调度。
黑潮军团入侵人类空域。
S级飞行员和S级战机是突破后期重甲战场的关键。
最终BOSS黑潮女王·弥赛亚在第1章结尾现身，并贯穿后续压迫感。
```

## 2. 世界观

人类城市上空出现黑色机械舰队“黑潮军团”。  
它们不是普通无人机群，而是由战争AI进化出的机械空中军团。

玩家接管“苍穹防线”，成为新任空战指挥官。  
女性飞行员组成的战姬小队负责执行空中作战。  
玩家负责选择飞行员、配置战机、推进关卡、突破黑潮重甲体系。

## 3. 最终BOSS

```text
名称：黑潮女王·弥赛亚
身份：黑潮军团主脑
形象：女性化机械AI，冷漠、高贵、压迫感强
首次登场：第1章第10关结尾
最终决战：第9章第10关
```

第1章第10关结尾，弥赛亚通过巨大投影出现，扫描玩家战机，并说出：

```text
人类的天空，已经不属于人类。
```

## 4. S级飞行员和S级战机的重要性

第2章开始，敌方出现重甲敌机。  
系统和当前选择的飞行员会提示玩家：

```text
普通火力可以打前期。
重甲敌机需要破甲。
S级飞行员和S级战机拥有更高穿甲能力。
第7章开始，S级组合会成为突破重甲核心防线的关键。
```

## 5. 剧情呈现方式

```text
不做长剧情。
不打断战斗。
不播放大段动画。
不让玩家长时间读文本。
```

剧情分为三层：

```text
章节剧情：每章开头和结尾交代目标。
关卡剧情：每关给标题、任务和简短通讯。
战斗中剧情：当前选择飞行员在左下角通讯框说话。
```

## 6. 叙事节奏

```text
序章：接入系统，学会战斗。
第1章：爽感推进，结尾揭示弥赛亚。
第2章：重甲敌机出现，明确S级战力价值。
第3-6章：敌人逐步升级，推动玩家强化。
第7章：重甲核心防线，S级组合真正生效。
第8章：反攻黑潮前线基地。
第9章：攻入黑潮母舰，最终决战弥赛亚。
```
