# 02_序章到第9章章节剧本

## 序章：苍穹启动

剧情功能：

```text
玩家以新任空战指挥官身份接入战姬作战系统，完成第一次出击，并确认黑潮军团正在入侵人类空域。
```

敌人变化：

```text
低威胁小型敌机
```

章节BOSS：

```text
无
```

玩法/商业功能：

```text
教学、基础战斗、当前飞行员通讯
```

章节开场：

- 苍穹防线正在失守。
- 你被临时任命为空战指挥官，接管战姬小队。
- 第一名飞行员已经完成接入，等待你的出击指令。

章节结尾：

- 序章空域清扫完成。
- 远方出现黑潮舰队信号，人类空域正式进入战争状态。

## 第一章：城市外围夺回战

剧情功能：

```text
战姬小队夺回城市外围空域，玩家获得第一次爽感推进；1-10结尾，最终BOSS黑潮女王·弥赛亚首次现身。
```

敌人变化：

```text
普通敌群、射击敌机、第一台章节BOSS
```

章节BOSS：

```text
外围压制机·黑鸦
```

玩法/商业功能：

```text
明确最终目标：弥赛亚
```

章节开场：

- 黑潮军团正在压向城市外围。
- 指挥官，战姬小队将从低空航线切入，夺回第一片空域。

章节结尾：

- 外围BOSS被击落后，天空中出现巨大黑色投影。
- 黑潮女王·弥赛亚扫描了玩家的战机，并宣告人类已经失去天空。

## 第二章：重甲空域

剧情功能：

```text
敌方重甲敌机出现，玩家在第二章明确知道S级飞行员和S级战机的重要性。
```

敌人变化：

```text
重甲敌机、护盾单位、重甲BOSS
```

章节BOSS：

```text
重甲核心机·铁幕
```

玩法/商业功能：

```text
强调S级飞行员与S级战机的破甲价值
```

章节开场：

- 黑潮军团开始投放重甲敌机。
- 普通火力仍能推进，但面对后续战场会明显吃力。
- 系统提示：S级飞行员与S级战机拥有更高破甲能力。

章节结尾：

- 铁幕被击退，但黑潮重甲体系已经展开。
- 飞行员提醒指挥官：后期必须准备S级战力。

## 第三章：沦陷空港

剧情功能：

```text
空港被黑潮控制，敌机数量和火力密度上升，玩家开始感受到持续强化的必要性。
```

敌人变化：

```text
射击敌机增多、多方向入场
```

章节BOSS：

```text
空港拦截机·灰隼
```

玩法/商业功能：

```text
推动战机强化
```

章节开场：

- 城市北部空港已经沦陷。
- 敌机将从多方向进入战场，清理效率决定推进速度。

章节结尾：

- 空港航线被重新打开。
- 黑潮主力舰队的位置被短暂捕获。

## 第四章：护盾量产线

剧情功能：

```text
护盾敌机被量产，玩家进一步理解破甲和强化的重要性。
```

敌人变化：

```text
护盾敌机、高减伤单位
```

章节BOSS：

```text
护盾母机·蓝棘
```

玩法/商业功能：

```text
强化破甲属性
```

章节开场：

- 黑潮在废弃工业区建立护盾量产线。
- 护盾单位会削弱普通火力，破甲属性开始变得关键。

章节结尾：

- 护盾母机被摧毁。
- 弥赛亚开始将玩家标记为可成长威胁。

## 第五章：精英猎杀令

剧情功能：

```text
黑潮派出精英战机针对战姬小队，玩家需要提升飞行员与战机的综合强度。
```

敌人变化：

```text
精英战机、锁定火力
```

章节BOSS：

```text
猎杀号令机·赤蝎
```

玩法/商业功能：

```text
推动飞行员养成
```

章节开场：

- 弥赛亚发布猎杀令。
- 黑潮精英战机开始针对战姬小队的飞行轨迹。

章节结尾：

- 猎杀编队被击穿。
- 战姬小队夺回中部高空通道。

## 第六章：主力舰队压境

剧情功能：

```text
黑潮主力舰队压境，弹幕密度和组合敌人明显增强，玩家迎来第一轮综合战力检测。
```

敌人变化：

```text
组合敌群、弹幕压力、精英编队
```

章节BOSS：

```text
主力舰护卫机·雷铠
```

玩法/商业功能：

```text
检测综合战力
```

章节开场：

- 黑潮主力舰队已经进入城市上空。
- 这不是清扫战，而是正面拦截。

章节结尾：

- 主力舰队护卫线被撕开。
- 第七空域的重甲核心防线暴露。

## 第七章：重甲核心防线

剧情功能：

```text
第七章是S级门槛章节，7-5开始显著压迫，7-10需要S级飞行员和S级战机才能稳定突破。
```

敌人变化：

```text
高减伤重甲核心、护盾单位、穿甲检测
```

章节BOSS：

```text
重甲核心·黑曜王座
```

玩法/商业功能：

```text
S飞行员+S战机真正生效
```

章节开场：

- 第七空域覆盖着黑潮重甲核心防线。
- 破甲不足的战机，会在这里被拖垮。

章节结尾：

- 黑曜王座被击穿。
- S级飞行员与S级战机的价值被完全验证。

## 第八章：反攻前线基地

剧情功能：

```text
玩家突破重甲防线后开始反攻，节奏回到爽感推进，同时为最终战铺垫。
```

敌人变化：

```text
前线基地防卫群、混合敌机
```

章节BOSS：

```text
基地防卫核·白烬
```

玩法/商业功能：

```text
爽感回流、反攻情绪
```

章节开场：

- 黑潮前线基地暴露在攻击航线内。
- 指挥官，反攻开始。

章节结尾：

- 前线基地被摧毁。
- 通往黑潮母舰的航线已经打开。

## 第九章：黑潮母舰决战

剧情功能：

```text
最终章，玩家攻入黑潮母舰核心，对决黑潮女王·弥赛亚。
```

敌人变化：

```text
最高火力密度、母舰护卫、最终BOSS
```

章节BOSS：

```text
黑潮女王·弥赛亚
```

玩法/商业功能：

```text
终局挑战
```

章节开场：

- 黑潮母舰悬停在城市最高空域。
- 弥赛亚的核心就在母舰内部。

章节结尾：

- 弥赛亚核心反应消失。
- 人类重新夺回天空。
