## 0. 设计目标与原则（Design Pillars）

1. **局外 = 氪金/养成吸引力**：品级越高，可装备的局外模块越多（B=0 / A=1 / S=2 / SS=3），高阶玩家能组出"攻防一体"的定制火力，这是抽卡与养成的核心拉力。
2. **局内 = 稳定地板**：3 个局内被动武器永远在线、可升级，保证任何品级都有基本手感。
3. **攻防一体、相互辅助**：6 个局外模块不是各自为战，而是能叠出"盾+散射+聚能+诱导+余烬"的协同闭环。
4. **主动技能要有"玩头"**：4 个大招各自承担不同战术角色（清屏/时停/分身/轰炸），不是换个皮肤的同款弹幕。
5. **侧翼火幕纹丝不动**：作为锚点参考项保留原行为——**单技能即左右双侧同时开火**。

> 攻击基准（沿用上一轮定稿的品级合计 ATK，作为所有倍率的锚）：
> B=40 / A=80 / S=120 / SS=160（战姬+战机合计，随战机强化·攻击缩放）。
> 所有"×D_ref"均指该基准下一发齐射的伤害。

## 1. 三层火力架构

```
┌─────────────────────────────────────────────────────────────┐
│  局外被动模块（大厅预配，按品级给槽）   ← 氪金/养成拉力核心   │
│  侧翼火幕 / 棱镜散射阵 / 立场发生器 / 聚能核心 /             │
│  诱导阵列 / 余烬回收                                         │
├─────────────────────────────────────────────────────────────┤
│  主动技能（S 解锁 2 / SS 解锁 4）          ← 战术爆发与救场   │
│  湮灭新星 / 时空裂解 / 镜像分身 / 轨道轰炸                   │
├─────────────────────────────────────────────────────────────┤
│  局内被动武器（战斗中升级，固定 3 个）     ← 稳定地板火力     │
│  脉冲光束 / 星芒散射 / 猎杀追踪                             │
└─────────────────────────────────────────────────────────────┘
```

**关键机制（待你拍板，见 §7-D1）**：每个已装备的局外模块可"override"一个局内被动槽；
SS 有 3 槽 → 可完全替换 3 个局内被动，组出纯局外定制 build；S 替换 2 个；A 替换 1 个；B 用纯基础。
这正是"SS 能拆掉局内被动"的落地方式，也是高阶玩家的身份感来源。

## 2. 6 个局外被动模块（玩家自选，按品级给槽）

> 数值全部为 **[PLACEHOLDER] 假设值**，需纸面模拟 + 实测后定稿。

### M1 · 侧翼火幕（Flank Fire Screen）— 不改
- **行为**：单侧挂载的侧向持续火力，**一个技能即左右双侧同时开火**（用户明确定义）。
- **攻击方式**：每 0.16s 齐射，左右各 1 道，每道 `0.35×D_ref`。
- **定位**：常驻侧翼 DPS 与补刀，不占用正面弹道，天然与其他正面模块互补。
- **氪金锚点**：SS 可叠装多个侧翼火幕（多槽），形成"双侧多重火幕"的视觉与数值霸权——这是用户点名的"多装备很有吸引力"案例。

### M2 · 棱镜散射阵（正面 110° 散射 + 子弹抵消）— 用户强制项
- **行为**：机首前置散射炮，覆盖 **正面 110° 扇形**。
- **攻击方式**：每 0.16s 5 发，均匀分布 110° 弧，每发 `0.7×D_ref`（散射有溅射损耗，部分会打空）。
- **防御特性**：**30% 概率抵消飞向玩家的非 BOSS 敌弹**（BOSS 弹不可抵消，规则硬上限）。
- **定位**：攻防一体核心件——既是正面主火力，又是廉价版"闪避"。与 M3 组合后抵消率可达 50%（见 §4 协同）。
- **设计意图**：用户要求"至少一个正面 110° 散射 + 30% 抵消"，此件即为强制锚点。

### M3 · 立场发生器（脉冲护盾）— 重新设计（原"轨道浮游炮"替换）
- **行为**：生成可再生的正面力场护盾。
- **机制**：护盾 absorbs **3 次**命中；破后 6s 再生 1 层。护盾**满层时**，M2 的子弹抵消率 **+20%**（即 30%→50%）。护盾被击破瞬间释放冲击波 `2×D_ref` AoE。
- **攻击方式**：无直接火力，纯防御 + 协同放大器。
- **定位**：把 M2 从"30% 闪避"升格为"半永久减伤"，是防御闭环的锁。

### M4 · 聚能核心（全武器增幅）— 重新设计（原"蜂群导弹舱"替换）
- **行为**：过载反应堆，对**全部武器伤害**生效。
- **机制**：所有武器（局内 P1~P3 + 局外 M1/M2 + 分身）伤害 **+25%**（乘法叠加）。
- **攻击方式**：无独立弹道，是 DPS 倍增器。
- **定位**：把 M1/M2 的火力真正"放大出来"，解决"弹道单一、数值温吞"的痛点——靠增幅而非堆同种子弹。

### M5 · 多普勒诱导阵列（时空操控）— 全新创意件
- **行为**：机身周围生成持续力场（半径 ~200px）。
- **机制**：
  - 场内**敌人减速 40%**（聚怪，让 M1/M2 命中率暴涨）；
  - 场内**敌弹被向外弯曲偏转**（防御：把原本打向你的弹道推离）；
  - 轻度把散兵**拉向场心**聚簇，便于 AoE 与散射收割。
- **攻击方式**：无伤害，纯"控制场"。
- **定位**：创意控制件，同时服务攻（聚怪）与防（偏弹），是攻防一体的黏合剂。

### M6 · 余烬回收系统（主动技能充能）— 全新创意件
- **行为**：击杀回收残骸能量。
- **机制**：每次击杀 **15% 概率**掉落 1 枚"余烬"；积满 **10 枚**后，下一次主动技能 **冷却 -40% 且伤害 +30%**，消耗全部余烬。
- **攻击方式**：无，纯资源循环。
- **定位**：把整局战斗的击杀节奏转化为大招节奏，让 4 个主动技能（§3）成为可预期的爆发点，串起整套体系。

### 6 件套设计自检
- 攻击多样性：M1 侧射 / M2 宽扇散射 / M4 增幅（无弹道但变数值）/ M5 控制场 / M3 护盾 / M6 资源——**不再只有"又一种追踪弹"**。
- 攻防分布：进攻向 M1/M2/M4；防御向 M3/M5；纽带 M6。任意 2~3 件组合都有正反馈。

## 3. 4 个主动技能（创意 + 真实效果，S 解锁 2 / SS 解锁 4）

> 全部为**新设计**，将替换现有 4 个 `shipSkills` 条目（设计稿，未改代码）。
> 主动伤害公式沿用现有：`伤害 = D_ref × damageBudget ÷ 发数`，天然随战机强化·攻击缩放。
> SS 直伤类大招额外 ×**1.6**（上一轮既定，保留）。

### A1 · 湮灭新星（Annihilation Nova）— 清屏/救场
- **解锁**：S + SS
- **效果**：以机身为中心爆发 `damageBudget ×4` 全屏 AoE，击退周围敌人并 **眩晕 1.5s**。
- **CD**：`[PLACEHOLDER] 25s`
- **玩家感受**："被包围时一键解围"，最直觉的 panic button。
- **创意点**：眩晕 + 击退制造 1.5s 真空，给 M2 抵消 / M5 偏弹争取喘息。

### A2 · 时空裂解（Chrono Rift）— 时停/输出窗口
- **解锁**：S + SS
- **效果**：全屏敌机与敌弹速度降至 **10%** 持续 **3s**；期间己方武器射速 **×2**。
- **CD**：`[PLACEHOLDER] 18s`
- **玩家感受**："子弹时间"——既是可以从容走位的防御窗，也是贴脸灌伤的进攻窗。
- **创意点**：攻防一体大招，和 M3/M5 的减速/偏弹形成"慢速领域"主题叠加。

### A3 · 镜像分身（Mirror Clone）— 分身/诱饵
- **解锁**：SS 专属
- **效果**：召唤 **2 个镜像分身**，复制本体武器火力（**60% DPS**），且 **50% 敌方仇恨**转向分身，持续 **8s**。
- **CD**：`[PLACEHOLDER] 30s`
- **玩家感受**："我打两份，还替我挡枪"，攻防双收益。
- **创意点**：唯一"分身"机制，配合 M4 增幅可让分身也吃加成，爆发极强。

### A4 · 轨道轰炸（Orbital Strike）— 预警/精准打击
- **解锁**：SS 专属
- **效果**：在屏幕标记 **3 个扇区**，**1.5s 预警**后依次落下毁灭性打击，合计 `damageBudget ×6`，高伤但需提前布点。
- **CD**：`[PLACEHOLDER] 35s`
- **玩家感受**："预判走位、定点清除"——考验玩家对敌群分布的读图，是技巧向大招。
- **创意点**：带 telegraph 的延迟 AoE，与"无脑即时清屏"形成对比，给高手操作空间。

### 解锁曲线（建议，待拍板 §7-D2）
- **S 解锁 A1 + A2**（清屏 + 时停，覆盖生存与输出最刚需的两类）。
- **SS 追加 A3 + A4**（分身 + 轰炸，组出完整战术库）。

## 4. 攻防一体 · 协同矩阵

| 组合 | 协同效果 | 类型 |
|------|---------|------|
| M2(散射) + M3(护盾) | 护盾满层时抵消率 30%→**50%** | 防+防=强防 |
| M4(聚能) + M1/M2 | 侧翼/散射伤害 +25% | 攻+攻=强攻 |
| M5(诱导) + M2/M1 | 敌人减速聚簇 → 命中率暴涨 | 控→攻 |
| M5(诱导) + M3 | 偏弹场 + 护盾 = 双层减伤 | 控+防 |
| M6(余烬) + 任意主动 | 击杀攒层 → 大招 -40%CD +30%伤 | 资源→主动 |
| A2(时停) + M4/A3 | 时停内 ×2 射速吃满增幅/分身 | 主动×被动 |
| A1(新星) + M5 | 眩晕期间诱导聚怪，清屏效率翻倍 | 主动×被动 |

**结论**：6 件任意 2~3 件组合均产生正向闭环；SS 三槽可组"M2 散射 + M3 护盾 + M4 聚能"或"3×侧翼火幕"等终极 build，达成用户要求的"相互辅助、攻防一体"。

## 5. 3 个局内固定被动（战斗中升级，不变更结构）

| 被动 | 攻击方式 | 基础 | 升级 |
|------|---------|------|------|
| P1 脉冲光束 | 正前单发直射 | `1.0×D_ref` / 0.16s | 每级 +0.1× |
| P2 星芒散射 | 正前 3 发窄扇 | `3×0.5×D_ref` / 0.16s | 每级 +0.1× |
| P3 猎杀追踪 | 追踪导弹 | `1×1.2×D_ref` / 0.4s | 每级 +0.1× |

> 这 3 个是"地板火力"，永远在线；SS 可用局外模块 override 其中至多 3 个（见 §1 机制）。

## 6. 品级吸引力曲线（为什么越抽越香）

| 品级 | 局外槽 | 可玩到的系统 | 体验落差 |
|------|-------|-------------|---------|
| **B** | 0 | 仅 3 局内被动 | 裸机手感，明确"缺装备" |
| **A** | 1 | +1 模块（建议首拿 M2 散射，立刻有 30% 闪避） | 第一次"攻防一体"甜头 |
| **S** | 2 | +2 模块 + **A1/A2 双大招** | 真·build 成型，能拆 2 个局内被动 |
| **SS** | 3 | +3 模块（可全拆局内被动）+ **4 大招全开** | 终极定制，3×侧翼/散射护盾聚能等霸权 build |

> 设计目标：B→A 给"能活"，A→S 给"能打"，S→SS 给"能秀 + 身份感"。每一阶都有可感知的战术增量，而非纯数值堆砌。
