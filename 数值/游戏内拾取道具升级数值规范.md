# 飞机拾取道具升级数值规范

本文档用于指导飞机小游戏内“拾取道具”的武器升级设计。目标是让 Codex 可以根据本文档直接实现道具名称、作用、升级等级与数值变化。

## 基础规则

- 所有武器道具最高等级为 10 级。
- 玩家拾取同名道具时，该武器等级 +1，最高不超过 10 级。
- 若玩家尚未拥有该武器，首次拾取后获得该武器并设为 1 级。
- 伤害系数用于乘以该武器的基础伤害。
- 本文档只定义升级数值，不限定具体美术表现。

## 武器一：穿云针

### 定位

单体点伤害武器。

### 作用

攻击范围小，但单次伤害高。适合打击正前方单个敌人或精英敌人。

### 升级规则

- 攻击频率随等级提升，从 1 秒 1 次提升到 0.1 秒 1 次。
- 伤害系数随等级提升，从 100% 提升到 200%。
- 攻击方向默认朝飞机正前方。
- 命中范围应较小，建议只检测正前方窄范围目标。

|---:|---:|---:|---:|
| 1 | 1.0 秒 | 1.00 次/秒 | 100% |
| 2 | 0.9 秒 | 1.11 次/秒 | 111% |
| 3 | 0.8 秒 | 1.25 次/秒 | 122% |
| 4 | 0.7 秒 | 1.43 次/秒 | 133% |
| 5 | 0.6 秒 | 1.67 次/秒 | 144% |
| 6 | 0.5 秒 | 2.00 次/秒 | 156% |
| 7 | 0.4 秒 | 2.50 次/秒 | 167% |
| 8 | 0.3 秒 | 3.33 次/秒 | 178% |
| 9 | 0.2 秒 | 5.00 次/秒 | 189% |
| 10 | 0.1 秒 | 10.00 次/秒 | 200% |

## 武器二：裂风波

### 定位

范围伤害武器。

### 作用

对飞机前方扇形范围内的敌人造成普通伤害。等级越高，覆盖角度越大，适合清理大量敌人。

### 升级规则

- 攻击范围为飞机前方扇形区域。
- 扇形角度从 1 级的 15° 提升到 10 级的 150°。
- 伤害系数从 100% 提升到 150%。
- 范围伤害的基础伤害应低于“穿云针”的基础伤害。

|---:|---:|---:|
| 1 | 15° | 100.0% |
| 2 | 30° | 105.6% |
| 3 | 45° | 111.1% |
| 4 | 60° | 116.7% |
| 5 | 75° | 122.2% |
| 6 | 90° | 127.8% |
| 7 | 105° | 133.3% |
| 8 | 120° | 138.9% |
| 9 | 135° | 144.4% |
| 10 | 150° | 150.0% |

## 武器三：灵蜂弹

### 定位

自动追踪伤害武器。

### 作用

自动锁定并攻击敌人。等级越高，可同时追踪的目标越多。适合处理移动敌人和分散敌人。

### 升级规则

- 自动寻找敌人并发射追踪弹。
- 可追踪目标数量从 1 个提升到 10 个。
- 伤害系数从 100% 提升到 150%。
- 自动追踪伤害的基础伤害应低于“穿云针”的基础伤害。
- 若场上敌人数量少于当前可追踪目标数量，只攻击现有敌人。

| 1 | 1 个 | 100.0% |
| 2 | 2 个 | 105.6% |
| 3 | 3 个 | 111.1% |
| 4 | 4 个 | 116.7% |
| 5 | 5 个 | 122.2% |
| 6 | 6 个 | 127.8% |
| 7 | 7 个 | 133.3% |

## 实现建议

### 推荐数据结构

可以将三种道具配置成数组或对象，字段建议如下：

```js
{
  id: "piercing_needle",
  name: "穿云针",
  type: "single",
  maxLevel: 10,
  levels: [
    {
      level: 1,
      damageMultiplier: 1.0,
      fireInterval: 1.0
    }
  ]
}
```

### 字段说明

| 字段 | 说明 |
|---|---|
| id | 程序内部使用的唯一标识 |
| name | 游戏内显示名称 |
| type | 武器类型：single、area、tracking |
| maxLevel | 最大等级，固定为 10 |
| damageMultiplier | 伤害系数，100% 写作 1.0 |
| fireInterval | 攻击间隔，仅“穿云针”需要 |
| coneAngle | 前方扇形角度，仅“裂风波”需要 |
| targetCount | 可追踪目标数量，仅“灵蜂弹”需要 |

### 道具拾取逻辑

```js
function pickupWeapon(player, weaponId) {
  const currentLevel = player.weapons[weaponId] || 0;
  const nextLevel = Math.min(currentLevel + 1, 10);
  player.weapons[weaponId] = nextLevel;
}
```

### 数值口径

- 伤害计算公式：最终伤害 = 基础伤害 * 伤害系数。
- 穿云针伤害系数：1 级为 1.0，10 级为 2.0。
- 裂风波伤害系数：1 级为 1.0，10 级为 1.5。
- 灵蜂弹伤害系数：1 级为 1.0，10 级为 1.5。
- 若实现中需要整数百分比，可以按表格百分比四舍五入。
