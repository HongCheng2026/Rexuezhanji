# Netlify H5 部署

这个目录就是 Netlify Drop 要上传的网页目录。

入口文件：

- `index.html`

部署方式：

1. 打开 `https://app.netlify.com/drop?utm_source=chatgpt.com`。
2. 把整个 `Netlify-H5` 文件夹拖进去，或上传 `Netlify-H5.zip`。
3. Netlify 生成临时网址后即可打开游玩。

关于域名 `rexuezhanji`：

Netlify Drop 的临时站点通常会自动生成随机域名。要固定成 `rexuezhanji.netlify.app`，需要登录 Netlify 账号并在站点设置里改 Site name；如果该名字已被占用，需要换一个相近名称。
